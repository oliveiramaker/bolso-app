# Bolso App

Aplicativo de finanças pessoais do Bolso, reconstruído como app nativo com React Native, Expo, TypeScript e SQLite.

## Stack
- Expo SDK 57
- React Native 0.86
- TypeScript
- Expo Router
- Expo SQLite

## Desenvolvimento
```bash
npm install
npx expo start
```

O banco local é persistente e funciona offline. A sincronização em nuvem será adicionada em uma etapa posterior.
